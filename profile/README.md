<h1 align="center">MkDocs NG</h1>

<p align="center">
  <strong>The maintained MkDocs that keeps your plugins working.</strong>
</p>

<p align="center">
  <a href="https://mkdocs-ng.github.io/mkdocs/">Documentation</a> ·
  <a href="https://mkdocs-ng.github.io/mkdocs/user-guide/migrating/">Switching from MkDocs</a> ·
  <a href="https://github.com/orgs/mkdocs-ng/discussions">Discussions</a>
</p>

MkDocs NG continues [MkDocs](https://github.com/mkdocs/mkdocs) where upstream
development stopped. It is a drop-in replacement: the same `mkdocs` command,
the same `mkdocs.yml`, and the same plugins and themes.

```sh
pip install mkdocs-ng
```

## Projects

| Project | What it is | Install |
| --- | --- | --- |
| [**MkDocs NG**](https://github.com/mkdocs-ng/mkdocs) | The static site generator. Python 3.10 to 3.15, built-in `llms.txt`, and many long-standing upstream bugs fixed. | `pip install mkdocs-ng` |
| [**Sumi**](https://github.com/mkdocs-ng/mkdocs-sumi) | A local-first documentation theme: docs, landing page, blog and releases from plain Markdown. | `pip install mkdocs-sumi` |
| [**MkDocs NG Material**](https://github.com/mkdocs-ng/mkdocs-material) | Material for MkDocs, maintained with security and bug fixes. | `pip install mkdocs-ng-material` |
| [**Catalog**](https://github.com/mkdocs-ng/catalog) | A ranked list of 300 plugins, themes and recipes for MkDocs. | |

## Why MkDocs NG

- **Your plugins keep working.** Thirty of the most used plugins are tested
  against every change.
- **Ready for AI tools.** Every site can publish `llms.txt` and a Markdown copy
  of each page.
- **Offline by default.** The built-in themes load nothing from CDNs and
  include no analytics.

## Get involved

Questions go to [Discussions](https://github.com/orgs/mkdocs-ng/discussions),
bugs to the issue tracker of the project they affect. Fixes, documentation and
plugin compatibility reports are all welcome; see the
